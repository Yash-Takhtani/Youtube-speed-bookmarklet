# Youtube-speed-bookmarklet
Lets you set the speed of a YouTube video up to 16x!
Pretty good for those boring lectures💤😒

# How to use
<img alt="tutorial" src="https://github.com/user-attachments/assets/aa4560f4-7260-48af-8059-7337d1b9dcfc"/>

 - Open index.html
 - Drag and drop the blue link to your bookmarks bar
 - Now open the youtube video
 - Click on the bookmark and set the speed!
